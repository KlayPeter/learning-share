搭建react

要做一个react有什么方法呢？

有三种方法是可以实现一个react

A HTML模板

<!DOCTYPE html>
<html>
  <head>
    <script src="../build/react.js"></script>
    <script src="../build/react-dom.js"></script>
    <script src="../build/browser.min.js"></script>
  </head>
  <body>
    <div id="example"></div>
    <script type="text/babel">
      // ** Our code goes here! **
    </script>
  </body>
</html>
  • 首先，最后一个 <script> 标签的 type 属性为 text/babel 。这是因为 React 独有的 JSX 语法，跟 JavaScript 不兼容。凡是使用 JSX 的地方，都要加上 type="text/babel" 。
  • 其次，上面代码一共用了三个库： react.js 、react-dom.js 和 Browser.js ，它们必须首先加载。其中，react.js 是 React 的核心库，react-dom.js 是提供与 DOM 相关的功能，Browser.js 的作用是将 JSX 语法转为 JavaScript 语法，这一步很消耗时间，实际上线的时候，应该将它放到服务器完成。

A JSX

然后有一个不得不提的语法：jsx

JSX本质：React.createElement的语法糖，也就是在js中写html代码

特点：

  • 看起来像 HTML，但在 JS 中使用。
  • 可以在其中直接写 表达式（注意是表达式，不是语句）。
  • 最终会被 Babel 编译成 React.createElement 调用。
  • 一般就是遇到这种<div>之类的就识别成createElement的，然后遇到{}就是进行解析
// 表达式嵌入
const name = 'Alice';
const element = <h1>Hello, React!</h1>;

//====
// JSX 本质 (编译后类似这样)
const element = React.createElement('h1', null, `Hello, ${name}!`);

注意：

  • JSX 标签必须闭合 (<div></div> 或 <img />)
  • 根节点必须有且只有一个（用 <div> 或 <React.Fragment> 包裹

B 组件 (Component)

React 最核心的思想：组件化。

函数组件（主流写法）

function Welcome(props: { name: string }) {
  return <h1>Hello, {props.name}</h1>;
}

类组件（了解即可）

class Welcome extends React.Component<{ name: string }> {
  render() {
    return <h1>Hello, {this.props.name}</h1>;
  }
}

使用组件

<Welcome name="Alice" />

C 状态 (State)

组件内部可变的数据。

函数组件里使用 Hook 来管理：useState。

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0); // 初始化 count=0

  return (
    <div>
      <p>{count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  );
}

外部传入的数据，只读，组件内部 不能修改。

用来提升组件复用性。

  return <div>{props.name} - {props.age}</div>;
}

<UserCard name="Bob" age={20} /> // 传属性

E 事件处理

和原生事件不同：

  • React 事件采用 驼峰命名（onClick）。
  • 传递函数，而不是字符串。
function Button() {
  function handleClick() {
    alert("Button clicked!");
  }

  return <button onClick={handleClick}>Click me</button>;
}

关于参数有

  • 事件参数e

  • 自定义参数

    事件绑定的位置改造成箭头函数的写法

    function App(){
  const clickHandler = (name)=>{
    console.log('button按钮点击了', name)
  }
  return (
    <button onClick={()=>clickHandler('jack')}>click me</button>
  )
}

  • 同时传也可以

    function App(){
  const clickHandler = (name,e)=>{
    console.log('button按钮点击了', name,e)
  }
  return (
    <button onClick={(e)=>clickHandler('jack',e)}>click me</button>
  )
}

F 条件渲染

React 中常见几种写法：

// 三元运算符 最常见，用于两种情况切换：
{isLoggedIn ? <Dashboard /> : <LoginPage />}

// && 短路运算 适合 只在满足条件时显示：
{unreadMessages.length > 0 && <span>You have messages</span>}

// if/else + 变量存储
// 有时逻辑复杂，不适合内联写三元，可以先处理再返回：
let content;
if (isLoading) {
  content = <p>Loading...</p>;
} else if (error) {
  content = <p>Error occurred</p>;
} else {
  content = <DataView />;
}

return <div>{content}</div>;

// 逻辑运算符（|| 默认值） 当值可能为 null/undefined 时给默认渲染：
{userInfo || <p>未登录</p>}

// Switch 写法（多分支情况）
switch (status) {
  case 'loading':
    return <Loading />;
  case 'success':
    return <Success />;
  case 'error':
    return <Error />;
  default:
    return <Default />;
}

G 列表渲染

常用 map 方法，需要加 key 保证唯一性（提升性能，避免错误）

  1. 基础写法
const todos = ['学习 React', '写作业', '打游戏'];

<ul>
  {todos.map((item, index) => (
    <li key={index}>{item}</li>
  ))}
</ul>
  1. 推荐使用唯一 id 作为 key
const todos = [
  { id: 1, text: '学习 React' },
  { id: 2, text: '写作业' },
  { id: 3, text: '打游戏' },
];

<ul>
  {todos.map(todo => (
    <li key={todo.id}>{todo.text}</li>
  ))}
</ul>
  1. 渲染组件列表
function TodoItem({ text }) {
  return <li>{text}</li>;
}

function TodoList({ todos }) {
  return (
    <ul>
      {todos.map(todo => <TodoItem key={todo.id} text={todo.text} />)}
    </ul>
  );
}
  1. 嵌套列表
const categories = [
  { id: 1, name: '学习', items: ['React', 'Vue'] },
  { id: 2, name: '娱乐', items: ['游戏', '电影'] },
];

<ul>
  {categories.map(category => (
    <li key={category.id}>
      {category.name}
      <ul>
        {category.items.map((item, index) => (
          <li key={index}>{item}</li>
        ))}
      </ul>
    </li>
  ))}
</ul>
  1. 空数组/无数据处理
{todos.length === 0 ? <p>暂无待办事项</p> : (
  <ul>
    {todos.map(todo => <li key={todo.id}>{todo.text}</li>)}
  </ul>
)}

key 的作用（列表渲染优化）:

  • key 帮助 React 高效更新 DOM。

  • 不能用 index（除非列表稳定不变），推荐使用唯一 id。

H 样式处理

三种常见方式：

  1. 内联样式 - 写法类似于原生 HTML，但 React 内联样式写法是 对象形式（驼峰命名）
<div style={{ color: 'red', fontSize: 20 }}>Styled Text</div>

  1. 普通 CSS / className - 最常见，直接写全局 CSS 文件，然后在 JSX 里用 className

    缺点：样式容易全局污染

/* App.css */
.title {
  color: blue;
  font-weight: bold;
}

import './App.css';

export default function App() {
  return <div className="title">普通 CSS 样式</div>;
}

  1. **CSS 模块 **

    • React 官方推荐的一种方式，可以做到 局部作用域，避免样式污染。

    • 命名一般是 xxx.module.css。

/* App.module.css */
.container {
  color: green;
  font-size: 18px;
}


import styles from './App.module.css';

export default function App() {
  return <div className={styles.container}>CSS Modules 样式</div>;
}
  1. 条件样式 动态切换样式时，可以用三元运算符、模板字符串，或第三方库 clsx
<div className={isActive ? 'active' : 'inactive'}>内容</div>

配合工具库（如 clsx）更方便：

import clsx from 'clsx';

<div className={clsx('btn', { 'btn-active': isActive })}></div>
  1. CSS-in-JS（Styled Components / Emotion）
  • 借助库把样式直接写在 JS/TS 文件里，推荐在大型项目中使用。
npm install styled-components
import styled from 'styled-components';

const Button = styled.button`
  color: white;
  background: blue;
  padding: 8px 16px;
  border-radius: 8px;

  &:hover {
    background: darkblue;
  }
`;

export default function App() {
  return <Button>Styled Components 按钮</Button>;
}
  1. Tailwind CSS（推荐前端项目）
  • 实用的原子化 CSS 框架，配合 React 开发效率极高。

npm install -D tailwindcss postcss autoprefixer

在 index.css 引入

@tailwind base;

组件

组件是什么

一个组件就是一个用户界面的一部分，它可以有自己的逻辑和外观，组件之间可以互相嵌套，也可以复用多次

// 1. 定义组件
function Button(){
  return <button>click me</button>
}

// 2. 使用组件
function App(){
  return (
    <div>
      {/* 自闭和 */}
      <Button/>
      {/* 成对标签 */}
      <Button></Button>
    </div>
  )
}

组件状态管理-useState

useState 是一个 React Hook（函数），它允许我们向组件添加一个状态变量, 从而控制影响组件的渲染结果

function App(){
  const [ count, setCount ] = React.useState(0)
  return (
    <div>
      <button onClick={()=>setCount(count+1)}>{ count }</button>
    </div>
  )
}

有一个要点是修改对象状态

在React中状态被认为是只读的，我们应该始终替换它而不是修改它, 直接修改状态不能引发视图更新

对于对象类型的状态变量，应该始终给set方法一个全新的对象 来进行修改

组件基础样式

React组件基础的样式控制有俩种方式，行内样式和class类名控制

组件通信

一 DOM组件

1 为DOM组件设置props

在 JSX 中，DOM 标签就是 React 内置组件，可以直接给它传递属性：

<img src="logo.png" alt="logo" />

类名要用 className（因为 class 是 JS 保留字）。

样式要用对象，属性名采用 驼峰命名：

<div style={{ backgroundColor: 'red', fontSize: 20 }}>Hello</div>

2 JSX 的展开语法

可以把一个对象直接展开成 props，方便复用。

import image from './logo'
function App() {
    const imgData = {
        className: 'small',
        style: {
            width: 200,
            height: 200,
            backgroundColor: 'grey'
        }
    }
    
    return (
    <div>
        <img
           src={image}
           alt=""
           {...imgData}
            />
    </div>
    )
}

export default App;

注意：这里的 {...} 只是 JSX 的特殊语法糖，不等同于 ES6 的对象展开（必须在标签里用）。

二、父组件传值给子组件（Props）

这是最常见的通信方式。

function Article({ title, content }) {
  return (
    <div>
      <h2>{title}</h2>
      <p>{content}</p>
    </div>
  );
}

export default function App() {
  return (
    <div>
      <Article title="标题1" content="内容1" />
      <Article title="标题2" content="内容2" />
    </div>
  );
}

Props 特点：

  • 单向传递（父 → 子）。
  • 只读，子组件不能修改 props。
  • 可以传递任意类型：字符串、数字、对象、函数、JSX。

三、将 JSX 作为 Props 传递（类似 Vue 插槽）

1. 默认 children

当我们把内容嵌套在组件的标签内部时，组件会自动在名为children的prop属性中接收该内容

function List({ children }) {
  return <ul>{children}</ul>;
}

<List>
  <li>列表1</li>
  <li>列表2</li>
</List>

2. 自定义插槽（具名插槽的替代方案）

function List({ title, children, footer = <div>默认底部</div> }) {
  return (
    <div>
      <h2>{title}</h2>
      <ul>{children}</ul>
      {footer}
    </div>
  );
}

<List title="列表" footer={<p>底部内容</p>}>
  <li>项1</li>
  <li>项2</li>
</List>

这样就能实现 Vue 的插槽思想。

四 子组件向父组件传值

和vue或者其他的差不多，主要父组件给子组件进行一个自定义事件的设置，然后通过事件触发后向父组件传递参数的形式

那么

import { useState } from "react";

function Detail({ onActive }) {
  const [status, setStatus] = useState(false);

  function handleClick() {
    const newStatus = !status;
    setStatus(newStatus);
    onActive(newStatus); // 调用父组件函数传值
  }

  return <button onClick={handleClick}>切换状态</button>;
}

export default function App() {
  function handleActive(status) {
    console.log("子组件传来的状态:", status);
  }

  return <Detail onActive={handleActive} />;
}

💡 这相当于 Vue 的 @emit。

五、跨层级组件传值（Context）

1. 问题：Prop drilling

如果层级很深，每一层都要传 props，会很冗余。

<App> → <Parent> → <Child> → <GrandChild>

在 React 中，父组件要给深层子组件传值时，通常要一层层通过 props 传递，这叫做 prop drilling（属性层层传递）。 这样代码会变得冗余、维护困难。

2. 解决方案：Context

Context 就是为了解决这个问题的，它可以让数据在组件树中全局共享，而不需要层层传 props。

// 1. 创建 Context
const ThemeContext = React.createContext();

// 2. 顶层提供数据
function App() {
  const [theme, setTheme] = useState("light");

  return (
      /* 在顶层组件 通过Provider组件提供数据 */
    <ThemeContext.Provider value={{ theme, setTheme }}>
      <Parent />
    </ThemeContext.Provider>
  );
}

// 3. 深层子组件直接消费数据
function GrandChild() {
  const { theme, setTheme } = React.useContext(ThemeContext);

  return (
    <div>
      <p>当前主题：{theme}</p>
      <button onClick={() => setTheme(theme === "light" ? "dark" : "light")}>
        切换主题
      </button>
    </div>
  );
}

表单控制

受控绑定

概念：使用React组件的状态（useState）控制表单的状态

其实有点像vue的双向绑定

function App(){
  const [value, setValue] = useState('')
  return (
    <input 
      type="text" 
      value={value} 
      onChange={e => setValue(e.target.value)}
    />
  )
}

非受控绑定

概念：通过获取DOM的方式获取表单的输入数据

function App(){
  const inputRef = useRef(null)

  const onChange = ()=>{
    console.log(inputRef.current.value)
  }
  
  return (
    <input 
      type="text" 
      ref={inputRef}
      onChange={onChange}
    />
  )
}
