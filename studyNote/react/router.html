一、认识路由

在传统网站里，一个网址对应一个 HTML 文件。 但是 React 项目是 单页面应用（SPA），只有一个 index.html，所以不同「页面」实际上是不同的 组件。

我们需要一个“路由系统”来决定：

  • 用户访问 /home 时展示 Home 组件
  • 用户访问 /login 时展示 Login 组件

这就是 React Router 的作用。

文档如下：

React Router Official Documentation

二、安装 React Router

先在项目里安装：

npm install react-router-dom

安装好之后，就能在代码里使用路由相关的 API 了。

注意：

  • React Router 6.4 开始推荐使用 Data API（createBrowserRouter）而不是 <BrowserRouter> 包裹。
  • 如果你在网上看到 BrowserRouter 的写法，那是旧版的教程。

三、配置最基本的路由

1. 创建路由文件

在 src/router/index.jsx 中写路由表：

// src/router/index.jsx
import { createBrowserRouter } from "react-router-dom";
import Home from "../views/Home";
import Login from "../views/Login";

// 定义路由表
const router = createBrowserRouter([
  {
    path: "/", // 访问 http://localhost:5173/
    element: <Home />, // 展示 Home 组件
  },
  {
    path: "/login", // 访问 http://localhost:5173/login
    element: <Login />, // 展示 Login 组件
  },
]);

export default router;

小提示：

  • path 是 URL 路径
  • element 是要渲染的组件

2. 挂载到应用入口

在 main.jsx 里挂载路由：

// src/main.jsx
import React from "react";
import ReactDOM from "react-dom/client";
import { RouterProvider } from "react-router-dom";
import router from "./router";

ReactDOM.createRoot(document.getElementById("root")).render(
  <React.StrictMode>
    {/* RouterProvider 就是路由容器 */}
    <RouterProvider router={router} />
  </React.StrictMode>
);

现在访问 / 就能看到 Home 页面，访问 /login 就能看到 Login 页面。 这就是最小可用的路由系统！

四、嵌套路由（父子页面）

实际开发中，我们常常有这种需求：

  • Home 页面有一个「内容区」
  • 内容区根据不同的子路由展示不同组件

这时候就要用到 嵌套路由。

1. 父组件里放占位符 <Outlet />

React Router 提供了一个专门的「占位符」组件 —— <Outlet />。

  • 父路由对应的组件，通常是页面的整体框架。
  • 子路由对应的组件，会渲染到 <Outlet /> 的位置。
// src/views/Home.jsx
import { Outlet, Link } from "react-router-dom";

export default function Home() {
  return (
    <div>
      <h1>这里是 Home 页面</h1>

      {/* 声明式跳转：点击后切换子路由 */}
      <nav>
        <Link to="content">内容页</Link> |
        <Link to="profile">个人中心</Link>
      </nav>

      {/* 子路由的内容会显示在这里 */}
      <Outlet />
    </div>
  );
}

2. 配置子路由

在路由表里配置 children 属性，就能把子路由挂到父路由下面。

// src/router/index.jsx
import Content from "../views/Content";
import Profile from "../views/Profile";

const router = createBrowserRouter([
  {
    path: "/home",
    element: <Home />,
    children: [
      {
        path: "content", // 注意 ⚠️ 这里不要加 /
        element: <Content />,
      },
      {
        path: "profile",
        element: <Profile />,
      },
    ],
  },
]);

💡 注意：

  • Outlet 就像 Vue 的 <router-view>。
  • 子路由路径不要加 /，否则会被识别成根路径。

五、错误页面（404 & 报错处理）

用户访问不存在的路径时，最好给一个友好的错误提示。

1. 通用错误页面

// src/views/ErrorPage.jsx
import { useRouteError } from "react-router-dom";

export default function ErrorPage() {
  const error = useRouteError(); // 捕获错误
  return (
    <div>
      <h2>页面出错啦！</h2>
      <p>{error.statusText || error.message}</p>
    </div>
  );
}

2. 在路由中使用

{
  path: "/login",
  element: <Login />,
  errorElement: <ErrorPage />, // 发生错误时显示
}

3. 404 页面

{
  path: "*", // 匹配所有未定义路径
  element: <ErrorPage />,
}

六、路由跳转方式

在 React Router 中，页面跳转有两种方式：

  1. 声明式跳转：通过标签来实现（写死在 JSX 里，适合导航栏、菜单等）。
  2. 编程式跳转：通过代码来控制（通常在点击按钮、提交表单、接口返回后使用）。

1. 声明式跳转（Link & NavLink）

import { Link, NavLink } from "react-router-dom";

function Navbar() {
  return (
    <nav>
      {/* 普通跳转 */}
      <Link to="/login">去登录</Link>

      {/* NavLink：会根据是否激活自动加 class */}
      <NavLink 
        to="/home" 
        className={({ isActive }) => (isActive ? "active" : "")}
      >
        首页
      </NavLink>
    </nav>
  );
}

💡 小提示：

  • Link = Vue Router 的 <router-link>，只负责跳转，不会刷新页面。
  • NavLink 比 Link 多一个 高亮功能，非常适合做导航栏。
  • isActive 可以拿到当前链接是否被激活，配合样式就能实现选中态。

👉 常见应用场景：

  • 顶部导航栏（首页 / 登录 / 关于）
  • 侧边栏菜单

2. 编程式跳转（useNavigate）

有时候不能写死路由，比如：登录成功后要跳转首页，或者用户点击按钮才跳转，这就需要 useNavigate。

import { useNavigate } from "react-router-dom";

function GoLoginButton() {
  const navigate = useNavigate();

  return (
    <button onClick={() => navigate("/login")}>
      点击跳转到登录页
    </button>
  );
}

👉 进阶用法：

navigate("/home", { replace: true });
  • replace: true 表示替换当前历史记录（相当于 window.location.replace），不会留下返回历史。
  • 默认是 push 模式（相当于 window.location.href），会保留历史，可以回退。

⚠️ 注意：useNavigate 只能在 函数组件中使用，不能在普通函数里用。

七、参数传递

路由跳转时，有两种常见的传参方式：

  1. Query 参数（searchParams）：常用于不敏感的数据，例如分页、搜索关键字。
  2. 路径参数（params）：常用于资源唯一标识，例如用户 ID、文章 ID。

1. Query 参数（searchParams）

这种方式就是 URL 的 ?key=value 格式，比如 /login?name=mmx&age=22。

发送参数：

// 使用 navigate 跳转并带参数
navigate("/login?name=mmx&age=22");

接收参数：

import { useSearchParams } from "react-router-dom";

function Login() {
  const [params] = useSearchParams();

  console.log(params.get("name")); // mmx
  console.log(params.get("age"));  // 22

  return <div>登录页面</div>;
}

💡 补充知识：

  • params.get("key") 获取参数值。
  • params.has("key") 判断是否存在某个参数。
  • params.toString() 可以把所有参数拼接成字符串，常用于拼接 API 请求。

👉 应用场景：

  • 搜索：/search?keyword=react
  • 分页：/articles?page=2&pageSize=10

2. 路径参数（params）

路径参数更直观，写在 URL 里，像 /user/1001。

发送参数：

navigate("/login/mmx/22");

在路由中声明：

{
  path: "/login/:name/:age?",  // ? 表示 age 可选
  element: <Login />,
}

接收参数：

import { useParams } from "react-router-dom";

function Login() {
  const { name, age } = useParams();
  console.log(name); // mmx
  console.log(age);  // 22

  return <div>用户名：{name}, 年龄：{age}</div>;
}

💡 小提示：

  • : 开头的参数是 必填，必须出现在 URL 中。
  • ? 表示参数 可选，比如 /login/mmx 也能匹配。
  • 如果参数缺失，useParams 会返回 undefined。

👉 应用场景：

  • 文章详情页：/article/123
  • 用户详情页：/user/1001
  • 产品详情页：/product/456

🔑 总结：什么时候用 Query？什么时候用 Params？

  • Query（searchParams）：数据可选、非唯一、可以组合（例如搜索条件、分页）。
  • Params（路径参数）：资源唯一、必须指定（例如用户 ID、文章 ID）。

比如：

  • 搜索文章：/search?keyword=react&page=2 ✅
  • 查看文章详情：/article/123 ✅

八、Data API 高级功能（React Router 独有）

从 v6.4 开始，React Router 提供了全新的 Data API：

  • loader → 在组件渲染前获取数据（类似 Vue 的 beforeEnter + setup）。
  • action → 在路由层处理表单提交逻辑（类似 Vue 的 actions 或服务端处理）。
  • lazy → 路由懒加载，按需加载组件，提升性能。

这些功能是 React Router 独有的优势，可以让路由和数据加载紧密结合，更加“声明式”。

1. loader（组件渲染前获取数据）

👉 loader 的作用：

  • 在组件渲染之前，就把数据准备好。
  • 避免组件“空白加载”的问题（不用写 useEffect + setState 了）。
  • 出错时会直接走到 errorElement。

示例：在页面渲染前获取接口数据

// src/views/Content.jsx
import { useLoaderData } from "react-router-dom";

// 1. 定义 loader：在页面渲染前调用
export async function loader() {
  const res = await fetch("https://jsonplaceholder.typicode.com/posts/1");
  if (!res.ok) throw new Error("加载失败！"); // 错误会被 errorElement 捕获
  return res.json();
}

// 2. 组件中使用 useLoaderData 获取数据
export default function Content() {
  const data = useLoaderData(); 
  return (
    <div>
      <h2>文章详情</h2>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
}
// router/index.jsx
import Content, { loader as contentLoader } from "../views/Content";
import ErrorPage from "../views/ErrorPage";

{
  path: "content",
  element: <Content />,
  loader: contentLoader,  // 绑定 loader
  errorElement: <ErrorPage />, // 错误时显示
}

💡 注意：

  • loader 必须返回一个 Promise（或值），返回的数据可以在组件中通过 useLoaderData() 拿到。
  • 如果接口报错，React Router 会自动跳转到 errorElement，不用自己写 try/catch。

👉 常见应用场景：

  • 文章详情页加载文章数据
  • 用户中心页面加载用户信息
  • 首页加载推荐内容

2. action（处理表单提交）

👉 action 的作用：

  • 专门用来处理 表单提交，比如登录、注册、搜索。
  • 搭配 <Form> 使用，不需要自己写 onSubmit。
  • 提交完成后，结果可以通过 useActionData 拿到。

示例：登录表单

// src/views/Login.jsx
import { Form, useActionData } from "react-router-dom";

// 1. 定义 action：处理表单提交
export async function action({ request }) {
  const formData = await request.formData();
  const name = formData.get("name");
  
  // 模拟登录逻辑
  if (!name) return { success: false, message: "请输入用户名" };

  return { success: true, user: name };
}

// 2. 页面组件
export default function Login() {
  const result = useActionData(); // 获取 action 返回的数据

  return (
    <div>
      <h2>登录</h2>
      {/* 注意这里用 Form，而不是普通 form */}
      <Form method="post">
        <input name="name" placeholder="输入名字" />
        <button type="submit">提交</button>
      </Form>
      
      {/* 显示 action 返回的结果 */}
      {result && (
        result.success 
          ? <p>欢迎你：{result.user}</p>
          : <p style={{ color: "red" }}>{result.message}</p>
      )}
    </div>
  );
}
// router/index.jsx
import Login, { action as loginAction } from "../views/Login";

{
  path: "/login",
  element: <Login />,
  action: loginAction, // 绑定 action
}

💡 注意：

  • <Form> 是 React Router 提供的，不是原生 HTML <form>。
  • <Form method="post"> 会自动触发对应路由的 action。
  • useActionData() 用来获取 action 返回的结果。
  • 常见场景：登录、注册、评论提交、搜索请求。

👉 相比传统写法（onSubmit + fetch），这种方式的好处是：

  • 逻辑更集中（action 和路由绑定，表单提交逻辑都在路由配置里）。
  • 自动错误处理（错误能走到 errorElement）。
  • 更接近服务端路由（像 Remix 框架一样）。

3. lazy（懒加载路由）

👉 为什么需要懒加载？

  • 如果你的应用有 20 个页面，用户第一次打开就加载全部代码，会很慢。
  • 懒加载可以让某些页面 只在访问时加载，减少首屏加载时间。

示例：懒加载 About 页面

// router/index.jsx
{
  path: "/about",
  lazy: async () => {
    // 动态导入组件
    const { default: About } = await import("../views/About");
    return { element: <About /> };
  },
}

💡 注意：

  • lazy 必须返回一个对象 { element: <组件 /> }。
  • 它和 React 的 React.lazy + Suspense 类似，但写法更简洁，直接挂在路由上。

👉 应用场景：

  • 体积较大的页面（比如“数据统计”、“后台管理”）
  • 用户不常访问的二级页面
  • 需要 SSR（服务端渲染）时，也能更好地做代码分割
