Hook

学一下react的Hook

什么是Hook？为什么要有 Hooks？

在 React 中，Hook（钩子） 是一类特殊的函数，它让你在 函数组件 中使用 state（状态）、生命周期、上下文 等功能，而不需要写类组件

在 Hook 出现之前，React 使用 类组件 来管理状态和生命周期，但存在一些问题：

主要是类组件问题，过于复杂，逻辑难以复用并且函数组件更加的轻量（让函数组件也能拥有 class 组件的能力,从而都用函数对象了）

Hook 让 React 代码更符合函数式编程范式

下面来说说常用的Hooks

1. useState—— 管理组件内部状态

用途：（基本最常用）

  • 用来在 函数组件 中存储和更新状态。
  • React 函数组件本身是 纯函数，不能直接保存变量（每次渲染都会重新执行函数）。
  • useState 提供一个“状态容器”，在渲染之间保持值不丢失。

语法：state: 当前的状态值; setState: 更新状态的函数。你可以直接传入新的状态值，或者传入一个接收前一个状态并返回新状态的函数

const [state, setState] = useState(initialState);
function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}

Vue 对比:

<script setup>
import { ref } from "vue";
const count = ref(0);
</script>

<template>
  <button @click="count++">{{ count }}</button>
</template>

注意事项

  • setState 是异步的，可能会批量更新。
  • 如果基于前一个状态更新，写法应为：setCount(prev => prev + 1)

2. useEffect—— 处理副作用（生命周期替代）

用途：

  • React 组件渲染是 纯 UI 渲染，不能在函数体里写副作用（如请求、定时器、DOM 操作）。
  • useEffect 专门用来处理这些副作用。它类似于 class 组件中的 componentDidMount, componentDidUpdate, 和 componentWillUnmount 的组合。

语法：

useEffect(() => {
  // 副作用逻辑
  return () => { /* 清理逻辑 */ };
}, [deps]);

参考代码

useEffect(() => {
  const timer = setInterval(() => console.log("tick"), 1000);
  return () => clearInterval(timer);
}, []); // [] 表示只执行一次（类似 onMounted）

Vue 对比

<script setup>
import { onMounted, onUnmounted } from "vue";

onMounted(() => {
  const timer = setInterval(() => console.log("tick"), 1000);
});
onUnmounted(() => {
  clearInterval(timer);
});
</script>

注意事项

  • 依赖数组决定执行时机：
    • 不写 → 每次渲染都执行
    • [] → 仅首次执行
    • [count] → 当 count 改变时执行
  • 清理函数相当于 Vue 的 onUnmounted。

3.useContext —— 跨层级数据共享

用途：

  • React 的 props 要层层传递，很麻烦
  • useContext 提供一种 全局上下文，子组件能直接拿到数据
  • 适合共享主题、用户信息等全局数据

语法：

const MyContext = createContext(defaultValue);
const value = useContext(MyContext);

参考代码：

const ThemeContext = createContext("light");

function App() {
  return (
    <ThemeContext.Provider value="dark">
      <Child />
    </ThemeContext.Provider>
  );
}
function Child() {
  const theme = useContext(ThemeContext);
  return <p>主题：{theme}</p>;
}

Vue 对比

<script setup>
import { provide, inject } from "vue";

// 父组件
provide("theme", "dark");

// 子组件
const theme = inject("theme", "light");
</script>

注意事项

  • Vue 的 provide/inject 用法和 React Context 很像。
  • 不适合管理复杂全局状态，复杂应用用 Redux / Zustand（Vue 用 Pinia）。

4.useReducer —— 处理复杂状态逻辑

用途：

  • useState 适合简单状态，但当逻辑复杂（比如多个条件更新）时会很乱。

  • useReducer 提供类似 Redux 的写法，把状态更新逻辑集中在 reducer 函数中。

  • 让 React 管理多个相对关联的状态数据

更新流程

语法：

const [state, dispatch] = useReducer(reducer, initialState);

分派action传参

分派action传参就是

分派action时如果想要传递参数，需要在action对象中添加一个payload参数，放置状态参数

参考代码

// 定义reducer

import { useReducer } from 'react'

// 1. 根据不同的action返回不同的新状态
function reducer(state, action) {
  console.log('reducer执行了')
  switch (action.type) {
    case 'INC':
      return state + 1
    case 'DEC':
      return state - 1
    case 'UPDATE':
      return state + action.payload
    default:
      return state
  }
}

function App() {
  // 2. 使用useReducer分派action
  const [state, dispatch] = useReducer(reducer, 0)
  return (
    <>
      {/* 3. 调用dispatch函数传入action对象 触发reducer函数，分派action操作，使用新状态更新视图 */}
      <button onClick={() => dispatch({ type: 'DEC' })}>-</button>
      {state}
      <button onClick={() => dispatch({ type: 'INC' })}>+</button>
      <button onClick={() => dispatch({ type: 'UPDATE', payload: 100 })}>
        update to 100
      </button>
    </>
  )
}

export default App

Vue 对比

<script setup>
import { reactive } from "vue";
const state = reactive({ count: 0 });

function dispatch(action) {
  if (action.type === "inc") state.count++;
  if (action.type === "dec") state.count--;
}
</script>

注意事项

  • useReducer 更适合 复杂状态转移（如表单、状态机）。
  • 小状态还是推荐用 useState。

5.useRef —— 引用 DOM 或保存变量

用途：

  • 在 React 中不能直接获取 DOM，必须用 useRef。
  • 还能用来保存一个不会随渲染而丢失的“记忆值”。

脱围机制：

用于保留不用于渲染的值。 你不会经常需要它们

语法

const ref = useRef(initialValue);

// ref会返回一个对象
// ref 是一个普通的 JavaScript 对象，具有一个名为 current 的属性，你可以对其进行读取或设置
{
	current: ''
}

参考代码

function Input() {
  const inputRef = useRef(null);
  useEffect(() => inputRef.current.focus(), []);
  return <input ref={inputRef} />;
}

Vue 对比

<script setup>
import { ref, onMounted } from "vue";
const inputRef = ref(null);

onMounted(() => inputRef.value.focus());
</script>

<template>
  <input ref="inputRef" />
</template>

注意事项

  • 改变 ref.current 不会触发重新渲染。
  • 常见用途：操作 DOM、保存上一次值、保存定时器 ID。

6.useMemo —— 缓存计算结果

用途（详细说明）

  • 避免在每次渲染时重复执行耗时计算。
  • 类似 Vue 的 computed。

语法

const memoValue = useMemo(() => computeFn(value), [value]);

参考代码

const expensive = useMemo(() => heavyCalc(count), [count]);

Vue 对比

const expensive = computed(() => heavyCalc(count.value));

注意事项

  • 只有依赖变化时才重新计算。
  • 不要滥用，否则代码可读性下降。

留意一个React.memo

作用：允许组件在props没有改变的情况下跳过重新渲染

组件默认的渲染机制

顶层组件发生重新渲染，这个组件树的子级组件都会被重新渲染

使用React.memo能优化组件只有props发生变化时才重新渲染子组件

import React, { useState } from 'react'

const MemoSon = React.memo(function Son() {
  console.log('子组件被重新渲染了')
  return <div>this is span</div>
})

function App() {
  const [, forceUpdate] = useState()
  console.log('父组件重新渲染了')
  return (
    <>
      <MemoSon />
      <button onClick={() => forceUpdate(Math.random())}>update</button>
    </>
  )
}

export default App

7.useCallback —— 缓存函数

上一小节我们说到，当给子组件传递一个引用类型prop的时候，即使我们使用了memo 函数依旧无法阻止子组件的渲染，其实传递prop的时候，往往传递一个回调函数更为常见，比如实现子传父，此时如果想要避免子组件渲染，可以使用 useCallback缓存回调函数

用途（详细说明）

  • 在 React 中，每次渲染函数都会重新创建。
  • 当函数作为 props 传递给子组件时，可能导致子组件重复渲染。
  • useCallback 用来缓存函数，避免这种性能问题。

语法

const memoFn = useCallback(() => { ... }, [deps]);

参考代码

const handleClick = useCallback(() => console.log("click"), []);

Vue 对比

  • Vue 响应式系统对函数传递优化较好，一般不用缓存函数。

注意事项

  • 常与 React.memo 一起使用。
  • 依赖数组必须写全。

8.useLayoutEffect —— 同步副作用

用途（详细说明）

  • 和 useEffect 类似，但它在 DOM 更新完成后、浏览器绘制前 执行。
  • 适合需要 读取并同步修改 DOM 的场景，比如测量宽高。

语法

useLayoutEffect(() => {
  // 同步副作用
}, [deps]);

参考代码

useLayoutEffect(() => {
  const width = divRef.current.offsetWidth;
  console.log("元素宽度:", width);
}, []);

Vue 对比

  • Vue 没有完全等价的 API，但 nextTick 可以做到类似效果。

注意事项

  • 会阻塞渲染，性能敏感时尽量用 useEffect。
  • 只在需要同步 DOM 的场景用。

9.useImperativeHandle —— 控制子组件暴露的 API

用途（详细说明）

  • 默认情况下，父组件通过 ref 拿到子组件 DOM。
  • 如果希望 子组件只暴露特定方法，可以用 useImperativeHandle。
  • 用于封装复杂组件时，给父组件一个受控 API。

语法

useImperativeHandle(ref, () => ({ ... }));

参考代码

const Child = forwardRef((props, ref) => {
  const inputRef = useRef();
  useImperativeHandle(ref, () => ({
    focus: () => inputRef.current.focus()
  }));
  return <input ref={inputRef} />;
});

Vue 对比

<script setup>
import { ref, defineExpose } from "vue";
const inputRef = ref(null);
defineExpose({ focus: () => inputRef.value.focus() });
</script>

注意事项

  • 必须配合 forwardRef 使用。
  • 破坏了组件封装性，慎用。

10. 自定义 Hook —— 逻辑复用

用途（详细说明）

  • React 没有 Vue 的 setup + 响应式系统。
  • 所以逻辑复用通过 自定义 Hook 完成，把状态 + 副作用封装成一个函数。

语法

function useXxx() {
  const [state, setState] = useState(...);
  useEffect(...);
  return { state, setState };
}

规则

  1. 声明一个以use打头的函数
  2. 在函数体内封装可复用的逻辑（只要是可复用的逻辑）
  3. 把组件中用到的状态或者回调return出去（以对象或者数组）
  4. 在哪个组件中要用到这个逻辑，就执行这个函数，解构出来状态和回调进行使用
  5. 不能在循环、条件中调用 Hook（必须在组件顶层）

参考代码

function useWindowSize() {
  const [size, setSize] = useState([window.innerWidth, window.innerHeight]);
  useEffect(() => {
    const update = () => setSize([window.innerWidth, window.innerHeight]);
    window.addEventListener("resize", update);
    return () => window.removeEventListener("resize", update);
  }, []);
  return size;
}

Vue 对比

function useWindowSize() {
  const width = ref(window.innerWidth);
  const height = ref(window.innerHeight);
  const update = () => {
    width.value = window.innerWidth;
    height.value = window.innerHeight;
  };
  onMounted(() => window.addEventListener("resize", update));
  onUnmounted(() => window.removeEventListener("resize", update));
  return { width, height };
}
